## Spreadsheet Data Processor

## Project Description
Spreadsheet Data Processor is a Python-based application for reading, validating, analyzing, filtering, and generating reports from CSV spreadsheet files.

The application allows the user to provide the path of a CSV file and specify the data type of each column. The application then validates the data, identifies missing and invalid values, performs calculations on numeric fields, allows records to be filtered, and generates a report in CSV format.

## Implemented Features

1. CSV File Loading
2. Data Reading
3. Validating data 
4. Calculating average and total
5. Filtering data
6. Creating report
7. Saving the report

## Steps to run the application

Step 1 : Install python
Step 2 : Clone or download the project
Step 3 : Run the application
```bash
python main.py
```

## Required Packages
The project primarily uses Python's standard library.

## Known limitations:

1. CSV files only
2. Data Types Must Be Provided Manually
3. Filtering Uses Exact Matching
4. Date and Datetime Formats
